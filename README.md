# 🔐 Cybersecurity Capstone Project

## 📌 Project Overview
This project is a comprehensive cybersecurity platform designed to improve security awareness, user authentication, and cyber threat management. It provides a secure environment with modern authentication features and an interactive user interface.

## ✨ Features
- User Authentication
- Two-Factor Authentication (2FA)
- Dashboard
- Policy Management
- Reports & Analytics
- User Profile Management
- Notification System
- Secure Backend APIs

## 🛠️ Technologies Used
### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- SQLite

## 📂 Project Structure
```
CYBERSECURITY-CAPSTONE
├── cyberbackend
├── frontend
├── README.md
```

## 🚀 How to Run

### Backend
```bash
cd cyberbackend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```
